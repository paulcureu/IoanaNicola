Uppercase, tracked text button — the only labelled CTA style (e.g. "Deschide portofoliul", "Descarcă PDF").

```jsx
<Button variant="primary" iconAfter="arrow-right">Deschide portofoliul</Button>
<Button icon="download" href="assets/portofoliu.pdf" download>Descarcă PDF</Button>
<Button variant="text">Cuprins</Button>
```

- `primary`: filled brown-900. Use at most once per screen.
- `outline`: hairline border, sand hover. Default.
- `text`: underlined label, turns clay on hover.
- Press = 1px nudge down, no scale.
